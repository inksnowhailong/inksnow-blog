# 手机端尺寸规范 + 三个布局 bug（2026-09-23，用户批准）

> 375 宽实测：正文输入 16px 合格；问题在"点得到的东西太小"和三处 bug。桌面（≥sm）保持现状。

## 三个 bug（必修）
1. 研究线卡输入框在手机上塌成 20px、「记下」飘到标题上：`lifeAskBar` 的 autoGrow 在容器 hidden 时量到 0。修：显示时重算（`IntersectionObserver`/`ResizeObserver` 或在 `showMore` 变化后 nextTick 重算；组件内部解决，别让调用方记得调）。
2. 读书行展开记内容：书名标签与输入框挤一行，输入框只剩 143px。修：标签独占一行（`书名 ›` 小字），输入框全宽。
3. 书弹窗底部残留提示「读到什么去打卡卡那行记」：删掉，底栏只剩「读完」次按钮（DONE 不渲染）。

```
所有可点               最小 40×40：文字钮 min-h-10 px-3；图标钮 h-10 w-10
快捷 +15 / +30         h-10 px-3 text-sm rounded-lg（一行放 +15 +30 ◎ ↺）
◎ 补到达标 / ↺ 清零    h-10 w-10
在读书 chip            h-9 px-3 text-sm；「＋」h-9 w-9；「›」h-9
文字次按钮             收尾 / 读完 / 读完 N / 已结 N：min-h-10 px-2 text-sm
底栏主按钮             h-11 px-5 text-base（标记完成 / 保存 / 记进展 / 结项）
弹窗内笔记行的 ×       h-9 w-9，手机常显（无 hover）
```
